## Accuracy & Scientific Methodology

We design every test with scientific rigor and technical precision.

### How We Measure Reaction Time

Our reaction time test uses JavaScript Performance APIs for high-precision timing, typically accurate to within 1-2 milliseconds. The measurement captures:

1. **Exact stimulus display time** – When the screen changes color
2. **User input timestamp** – When you click/tap
3. **Latency compensation** – Browser and rendering delays minimized

We optimize the code to minimize processing overhead and use event timestamps from the browser's performance timeline rather than less accurate timing methods.

### Understanding Measurement Limitations

While we strive for maximum accuracy, several factors can affect measurements:

**Device Factors:**
- Display refresh rate (60Hz adds ~8ms uncertainty, 144Hz adds ~3ms)
- Input device latency (wired mice: 1-5ms, wireless: 5-15ms, touchscreens: 30-100ms)
- Browser processing overhead (1-5ms typically)
- System performance and background processes

**Environmental Factors:**
- User fatigue and attention
- Lighting and visual conditions
- Physical comfort and posture
- Time of day and circadian rhythms

For most accurate results, we recommend:
- High refresh rate display (120Hz or higher)
- Wired mouse with high polling rate
- Closing unnecessary browser tabs and applications
- Testing in a distraction-free environment
- Consistent testing conditions for progress tracking

**Important:** Our tools are designed for training, self-assessment, and entertainment. They are not medical devices and should not be used for clinical diagnosis or safety-critical decision-making.
